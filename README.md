# 🚀 AI Data Intelligence Platform

An end-to-end AI-powered analytics platform that enables users to upload datasets and instantly perform data visualization, exploratory data analysis (EDA), automated data cleaning, machine learning predictions, and AI-powered dataset insights through an interactive web interface.

# ✨ Features

### 📂 Dataset Management
- Upload CSV and Excel datasets
- Instant dataset preview
- Automatic dataset statistics
- Support for datasets up to 50 MB

### 📊 Data Visualization
- Interactive Pie Charts
- Bar Charts
- Scatter Plots
- Correlation Heatmaps
- Distribution Analysis

### 🤖 AI Insights
- Automatic dataset summary
- Missing value detection
- Duplicate detection
- Correlation analysis
- Recommended Machine Learning task
- Suggested algorithms

### 💬 AI Dataset Chat Assistant
- Ask questions about uploaded datasets
- Dataset statistics
- Column information
- Missing value analysis
- Machine learning recommendations

### 🧹 Data Cleaning
- Remove duplicate rows
- Fill missing numeric values
- Fill missing categorical values
- Download cleaned dataset

### 📈 Machine Learning Predictions
- Automatic feature selection
- Linear Regression predictions
- Dynamic target column selection
- Real-time prediction interface

### 📑 Reports
- Automated EDA report generation
- Statistical summary
- Downloadable PDF reports

# ⚙️ Installation

## Clone Repository

```bash
git clone https://github.com/Prajyoti04/AI-Data-Intelligence-Assistant.git
```

## Backend

```bash
cd server

python -m venv venv

venv\Scripts\activate

pip install -r requirements.txt

uvicorn server.main:app --reload
```

Backend runs on:

```
http://localhost:8000
```

---

## Frontend

```bash
cd client-react

npm install

npm run dev
```

Frontend runs on:

```
http://localhost:5173
```
